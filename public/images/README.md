# Personal Photograph & Brand Assets Directory

## 1. Hero Section Personal Photograph
Place your professional portrait photograph in this folder (`public/images/`) using any of the following filenames for **automatic detection**:
- `public/images/safdar-khan.webp`
- `public/images/safdar-khan.png`
- `public/images/safdar-khan.jpg`
- `public/images/safdar-khan.jpeg`

Or specify a custom path in `src/config/siteConfig.ts` under `PORTRAIT_CONFIG.imageSrc`.

## 2. Official Downloadable PDF CV
